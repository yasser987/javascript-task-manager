# JavaScript Task Manager

A responsive task management application built with vanilla JavaScript and persistent browser storage.

## Features

- Add, edit, complete, and delete tasks
- Persist tasks with Local Storage
- Responsive layout for mobile and desktop
- Accessible labels, status announcements, and keyboard focus
- Clear empty and completion states

## Built With

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- DOM APIs
- Local Storage
